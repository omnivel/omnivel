## ✦ About Omnivel

Omnivel is being developed as a unified AI assistant that combines
conversational experiences, creative tools, intelligent assistance, and
integrations with multiple AI services.

The goal is to give users one place to explore ideas, create, analyze
information, learn, and solve problems---without constantly switching
between separate tools.

## 🔐 API Configuration & Security

Some features require API credentials from the relevant providers.

**Security guidelines:**

-   Never commit private API keys to a public GitHub repository.
-   Do not place secret keys directly in browser-side HTML or
    JavaScript.
-   Use a secure backend or server-side environment variables for
    private credentials.
-   Anyone running their own deployment should configure their own
    credentials securely.

Setup instructions should be added once the project's actual runtime and
backend configuration are finalized.
