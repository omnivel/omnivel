## Meet Omnivel

Omnivel is an AI-powered workspace designed to bring several useful AI experiences together. Ask questions, explore live information, work with images, talk through voice and use supported tools — without treating every capability as a separate product.

The idea is simple: **make AI a place to think, discover and create, not just a place to type prompts.**

## What you can do

| ✦ Experience | What it helps you do |
|---|---|
| **AI Conversations** | Ask questions, explore ideas and continue context-aware conversations. |
| **Live Web Search** | Find current information on the web and ask follow-up questions. |
| **Live Voice** | Talk with the assistant through supported voice conversations. |
| **Image Generation** | Turn a written idea into a visual using supported image services. |
| **Image Understanding** | Share an image and ask the assistant to analyse or explain it. |
| **Doodle & Creativity** | Explore visual ideas with creative and doodle tools. |
| **Coding & LaTeX** | Get help with programming, technical ideas and mathematical notation. |
| **Interactive Tools** | Use supported experiences such as maps, timers and alarms. |
| **Connected Workspace** | Revisit chats, branch conversations and organise library items and artifacts. |

## Meet Owl 🦉

**Owl is the agent experience at the heart of Omnivel.**

Owl connects conversational context with tools available inside the application. It is designed to make the assistant experience more interactive and help users move through supported workflows.

- **Context-aware assistance** — work with the ongoing conversation.
- **Tool-supported workflows** — use capabilities available in the app.
- **Creative assistance** — access supported image-generation experiences.
- **Interactive utilities** — work with available task tools such as timers and alarms.
- **User control** — keep permissions and action approvals clear.

Owl works within the tools and permissions enabled in the current build.

## AI model & service integrations

Omnivel follows a flexible, multi-provider approach. The project includes integrations and service support across:

| Provider / Service | Role in the platform |
|---|---|
| **Google Gemini** | General AI capabilities |
| **Groq** | Fast model inference |
| **Hugging Face** | Additional model access |
| **Pollinations AI** | Image-generation and related services |

Model availability can vary by provider, API access and configuration.

## Security

- Never commit API keys, tokens or private credentials to a public repository.
- Do not expose production secrets in client-side JavaScript or browser storage.
- Protect production credentials with secure server-side infrastructure.
- Review permissions before enabling actions that affect user data or external services.
